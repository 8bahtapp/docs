คำถามที่พบบ่อย

จัดการใบอนุญาต PDFelement ได้ที่ PDFelement Account Center โดย Sign in ด้วยอีเมล Admin

ผู้ดูแลระบบสามารถนำ Redeem Code (หรือ Serial number) ไปลงทะเบียนได้ที่ PDFelement Account Center โดยลงชื่อเข้าใช้แล้วไปที่เมนู Plan & Products > เลือก Redeem Membership จากนั้นกรอกรหัสแล้วกด Submit (แนะนำให้ใช้อีเมลกลางขององค์กรหรือของแอดมินในการแลกรหัส เนื่องจากใช้ได้เพียงครั้งเดียว)

หลังจากแลกรหัสแล้ว ให้ไปที่เมนู Manage Team > Team Users เลือกทีมแล้วกด Add User จากนั้นระบุอีเมลของพนักงาน เลือกบทบาทเป็น Admin หรือ User ตั้งรหัสผ่านเริ่มต้น และทำเครื่องหมายถูกหน้าผลิตภัณฑ์ที่ต้องการมอบใบอนุญาตให้เรียบร้อย

ดาวน์โหลดไฟล์ติดตั้งเวอร์ชันล่าสุดได้จากหน้า ดาวน์โหลด PDFelement เมื่อติดตั้งเสร็จแล้วให้เปิดโปรแกรมขึ้นมา จากนั้นเลือก Sign in ด้วยอีเมลและรหัสผ่านที่แอดมินกำหนดไว้ ก็จะสามารถเริ่มต้นใช้งานได้ทันที

แนะนำให้ทำการถอนใบอนุญาต (Deactivate) ก่อนเสมอ โดยเปิดโปรแกรม PDFelement ขึ้นมา จากนั้นคลิกที่ปุ่มบริเวณมุมบนขวาของโปรแกรม แล้วเลือก Log out เพื่อคืนสิทธิ์ใบอนุญาตก่อนจะเปลี่ยนเครื่องหรือลบโปรแกรม

แอดมินสามารถเข้าไปที่ PDFelement Account Center ไปที่ Manage Team > Team Users กด Edit ที่รายชื่อพนักงานคนเดิมเพื่อเอาเครื่องหมายถูกออกจากตัวผลิตภัณฑ์เพื่อดึงสิทธิ์คืน จากนั้นกด Add User เพื่อเพิ่มอีเมลของพนักงานคนใหม่เข้ามารับสิทธิ์แทนได้ทันที
