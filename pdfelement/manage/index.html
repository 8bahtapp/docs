PDFelement Manage License

วิธีจัดการใบอนุญาต

เพื่อเริ่มต้นใช้งานจะต้องแลกรหัส Redeem Code ก่อน จากนั้นสามารถจัดการใบอนุญาตโดยเพิ่มอีเมลผู้ใช้งาน

License จะถูกผูกกับอีเมลที่ลงทะเบียน และ Redeem Code ใช้ได้เพียงครั้งเดียว — แนะนำให้ใช้อีเมลกลางหรือของผู้ดูแลในการแลกรหัส

ขั้นตอนการแลกรหัส

  • ไปที่ PDFelement Account Center
  • Sign in หากเคยมี Wondershare ID แล้ว หรือเลือก Create account หากไม่เคยมี
  • ไปที่ Plan & Products
  • เลือก Redeem Membership
  • ใส่ Redeem Code (หรือเอกสารอาจระบุว่า Serial number)
  • คลิก SUBMIT เพื่อยืนยันการแลกรหัส

ขั้นตอนการจัดการใบอนุญาต

  • เลือก Manage Team > Team Users
  • เลือกทีมที่ต้องการ (กรณีมีหลายทีม) > Submit
  • คลิก Add User
  • ใส่ Email ของผู้ใช้งาน
  • เลือก Roles เป็น Admin หรือ User > Submit
  • สามารถตั้ง Password ของผู้ใช้งานได้ทันที
    • ผู้ใช้งานสามารถเปลี่ยนเองได้ภายหลัง
  • ทำเครื่องหมาย ✓ หน้าโปรดักส์ที่ต้องการ > เลือก Submit
  • สามารถแก้ไขได้โดยกด Edit ที่ด้านหลังของแต่ละผู้ใช้งาน
  • สามารถทำซ้ำขั้นตอนเดิมให้ครบตามจำนวนใบอนุญาต

ติดตั้งและเปิดใช้งาน

ขั้นตอนติดตั้งและเปิดใช้งาน

  • ดาวน์โหลดไฟล์ติดตั้ง PDFelement ที่หน้า ดาวน์โหลด
  • ดับเบิลคลิกที่ไฟล์ เพื่อติดตั้งโปรแกรม
  • คลิก Install
  • คลิก Start Now
  • เปิดโปรแกรม
  • Sign in ด้วยอีเมลของผู้ใช้งาน
  • เป็นอันเสร็จเรียบร้อย

ถอนใบอนุญาต

แนะนำให้ถอนใบอนุญาตก่อน Uninstall โปรแกรม หรือก่อนเปลี่ยนเครื่องคอมพิวเตอร์

วิธีถอนใบอนุญาต (Deactivate)

  • เปิดโปรแกรม PDFelement
  • มองหาปุ่มที่มุมบนขวาของโปรแกรม
  • เลือก Log out
  • เสร็จสิ้นขั้นตอนการถอนใบอนุญาต

วิธีเปลี่ยนอีเมลผู้ใช้งาน

ขั้นตอนการเปลี่ยนอีเมลผู้ใช้งาน

  • ไปที่ PDFelement Account Center
  • Sign in ด้วยอีเมลแอดมิน
  • เลือก Manage Team > Team Users
  • เลือกทีมที่ต้องการ (กรณีมีหลายทีม) > Submit
  • คลิก Edit ที่อีเมลผู้ใช้งานท่านเดิม
  • ทำเครื่องหมาย ✓ ออกจากหน้าโปรดักส์ > เลือก Submit
  • เพิ่มผู้ใช้งานใหม่โดยคลิก Add User
  • ใส่ Email ของผู้ใช้งานใหม่
  • เลือก Roles เป็น Admin หรือ User > Submit
  • สามารถตั้ง Password ของผู้ใช้งานได้ทันที
    • ผู้ใช้งานสามารถเปลี่ยนเองได้ภายหลัง
  • ทำเครื่องหมาย ✓ หน้าโปรดักส์ที่ต้องการ > เลือก Submit

ข้อมูลเพิ่มเติม

  • คำถามที่พบบ่อย
  • วิธีเปลี่ยนอีเมลผู้ใช้งาน
