D5 Pro - ใบอนุญาตและเปิดใช้งาน

สำหรับ D5 Pro โปรดใช้ 1 Redeem Code ต่อ 1 Email เท่านั้น

วิธีแลกรหัสใช้งาน D5 Pro

  • ไปที่ D5 Account
  • Sign in หากเคยมี D5 Account อยู่แล้ว (โปรดมั่นใจว่าเป็นอีเมลที่ถูกต้อง)
    • Sign Up หากไม่เคยมีบัญชี
  • ที่เมนู Settings เลื่อนลงไปด้านล่าง มองหาและคลิกคำว่า Redeem Code
  • คลิก Send to Email ระบบจะส่ง Verification Code ไปที่อีเมลของคุณ
    • นำชุดตัวเลข Verification Code นั้นมาใส่ในช่องให้ถูกต้อง
  • ใส่รหัส Redeem Code (ชุดตัวเลขกับอักษรภาษาอังกฤษ 8 ตัว)
  • ใบอนุญาตจะผูกกับอีเมลนั้นๆ เป็นระยะเวลา 1 ปี Code
  • คลิก Redeem เพื่อยืนยันการแลกรหัส เมื่อสำเร็จหน้าจอจะแสดงวันหมดอายุของคุณ

วิธีติดตั้งและเปิดใช้งาน D5 Pro

  • ดาวน์โหลดไฟล์ติดตั้ง D5 ที่นี่
  • ดับเบิลคลิกไฟล์ติดตั้ง แล้วกด Install — รอติดตั้งสักครู่
  • เปิดโปรแกรม D5 Render แล้วคลิก Sign in
  • ใส่อีเมลและรหัสผ่านที่ผูก License Pro ไว้
  • หลัง Sign in สำเร็จ ระบบจะแสดงสถานะ Pro
  • หากยังแสดง Free โปรดตรวจสอบการ Redeem Code

D5 for Teams - ใบอนุญาตและเปิดใช้งาน

เมื่อสั่งซื้อสำเร็จคุณจะได้รับอีเมลคำเชิญเพื่อเริมต้นใช้งาน D5 for teams

วิธีจัดการใบอนุญาต D5 for Teams

  • ตรวจสอบอีเมลที่ได้รับจาก D5 หรือค้นหาอีเมลที่ส่งมาจาก alert@dm.d5techs.com
  • คลิกปุ่ม Accept ในอีเมลคำเชิญ
  • Sign in หากเคยมี D5 Account อยู่แล้ว หรือเลือก Sign Up / คลิก Forgot Password? หากยังไม่มีบัญชีหรือจำรหัสผ่านไม่ได้
  • ไปที่หน้าจัดการระบบทีม D5 Team Management
  • เลือกโปรไฟล์ Team ของคุณ
  • ที่มุมบนขวา ให้คลิกปุ่ม Invite เพื่อเพิ่มอีเมลผู้ใช้งาน
  • กรอกอีเมลของผู้ใช้งานที่ต้องการเชิญเข้าสู่ทีม
  • คลิก Send เพื่อส่งคำเชิญ
  • ผู้ใช้งานจะได้รับอีเมลคำเชิญและจะต้องกดเข้าร่วม (Join) เพื่อเริ่มต้นใช้งาน
    • Status - Invited: อยู่ระหว่างรอผู้ใช้งานกดตอบรับคำเชิญ
    • Status - Join: ผู้ใช้งานเข้าร่วมทีมสำเร็จแล้ว
  • Account Attributes (การกำหนดสิทธิ์):
    • Editable: สามารถใช้งาน D5 ได้
    • Manage Only: สำหรับแอดมินที่เข้ามาจัดการใบอนุญาตเท่านั้น ไม่สามารถเปิดใช้งานโปรแกรม D5

วิธีติดตั้งและเปิดใช้งาน D5 for Teams

  • โปรดเช็คอีเมลที่ได้รับจาก D5 หรือค้นหาอีเมลที่มาจาก notification@d5techs.com
  • คลิกปุ่ม Accept Invitation ในอีเมล
  • Sign in หากเคยมี D5 Account อยู่แล้ว หรือเลือก Sign Up หากไม่เคยมีบัญชี (กรณีจำรหัสผ่านไม่ได้ให้คลิก Forgot Password?)
  • ใส่ชื่อที่ต้องการใช้งาน จากนั้นคลิก Confirm
  • ดาวน์โหลดไฟล์ติดตั้งโปรแกรมได้ที่ D5 Launcher Download
  • ดับเบิลคลิกที่ไฟล์ที่ดาวน์โหลดมา เพื่อเริ่มต้นติดตั้งโปรแกรม
  • คลิกทำเครื่องหมายที่ช่องข้อตกลงการใช้งาน (User Agreement)
  • คลิก Install Now → รอระบบติดตั้งสักครู่ → จากนั้นเปิดโปรแกรม D5 Launcher
  • Sign in เข้าสู่ระบบด้วยอีเมลและรหัสผ่านของคุณให้เรียบร้อย
  • เมื่อเข้าสู่ระบบสำเร็จ สถานะบัญชีจะแสดงเป็น Team
  • คลิกที่เมนู Workflow → คลิก Install D5 → รอระบบดำเนินการติดตั้งจนเสร็จสิ้น
  • Note: โปรดตรวจสอบและมั่นใจว่าคอมพิวเตอร์ของคุณเชื่อมต่ออินเทอร์เน็ตอยู่ตลอดเวลาในขณะใช้งาน D5

ถอนใบอนุญาต Deactivate

ข้อควรระวัง — ควร Deactivate ก่อนเสมอเมื่อต้องการ Uninstall หรือเปลี่ยนเครื่อง เพื่อให้ License พร้อมใช้งานบนเครื่องใหม่

วิธี Deactivate ผ่านโปรแกรม D5 (แนะนำ)

  • เปิดโปรแกรม D5 Launcher บนเครื่องที่ต้องการถอน
  • คลิกที่ ชื่อผู้ใช้งาน มุมล่างซ้าย
  • คลิก Log out หรือ
  • ยืนยันการถอน — License จะพร้อมใช้งานบนเครื่องใหม่ทันที

Unbind ผ่าน D5 Account Portal (กรณีเข้าถึงเครื่องเดิมไม่ได้)

  • ไปที่ D5 Account Portal
  • Sign in ด้วยอีเมลของคุณ
  • ไปที่เมนู Settings
  • มองหา Device Management
  • เลือกเครื่องที่ต้องการถอน แล้วคลิก Unbind
  • ยืนยันการถอน License จะถูกปลดออกจากเครื่องนั้น
