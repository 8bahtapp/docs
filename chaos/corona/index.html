คำถามที่พบบ่อย

จัดการใบอนุญาตได้ที่ my.chaos.com โดย Sign in ด้วยอีเมลที่ใช้สั่งซื้อ

Named License ผูกกับอีเมลผู้ใช้งานแต่ละคน ใช้งานได้เฉพาะอีเมลที่กำหนด — Floating License ใช้ร่วมกันได้ สามารถใช้อีเมลเดียวกันทุกเครื่อง หรือแบ่งปันใบอนุญาตตามจำนวนที่ซื้อ

ใช่ ต้องติดตั้งโปรแกรม host เช่น 3ds Max หรือ Cinema 4D ก่อน แล้วจึงติดตั้ง Corona ไฟล์ติดตั้ง Corona สำหรับแต่ละ host จะใช้ไฟล์แยกกัน

เปิดใช้งานได้ที่แอปพลิเคชัน Corona คลิก Render(ไอค่อนกาน้ำ) คลิก Sign in ด้วยอีเมลและรหัสผ่านของคุณ

การใช้งานแนะนำให้เชื่อมต่ออินเทอร์เน็ตเพื่อตรวจสอบใบอนุญาตตลอดเวลา

ไปที่ accounts.chaos.com แล้วเลือก "Forgot password" เพื่อรีเซ็ตรหัสผ่านผ่านอีเมล

Named License ใช้ได้ 1 เครื่องต่อ 1 อีเมล — Floating License ใช้ได้พร้อมกันตามจำนวนที่ซื้อ เช่น 3 Floating ใช้ได้พร้อมกัน 3 เครื่อง

ไปที่ my.chaos.com/products จะแสดงรายการใบอนุญาตและวันหมดอายุทั้งหมด หรือดูคู่มือที่ วิธีเช็ควันหมดอายุ

ตรวจสอบว่า Admin ได้ Assign โปรดักส์ให้อีเมลของคุณแล้วใน my.chaos.com — หรือลอง Sign out แล้ว Sign in ใหม่ที่ Chaos License Server

Admin ต้อง Unassign โปรดักส์จากอีเมลเดิมก่อน แล้วเพิ่มและ Assign ให้อีเมลใหม่ใน my.chaos.com ดูคู่มือที่ วิธีเปลี่ยนอีเมลผู้ใช้งาน

โดยปกติใบอนุญาตจะต่ออายุอัตโนมัติ ผู้ใช้งานสามารถใช้งานต่อเนื่องได้เลยโดยไม่ต้องทำขั้นตอนใหม่

ผู้ใช้งานต้องสร้างบัญชี Chaos ก่อนที่ accounts.chaos.com/register โดยใช้อีเมลเดียวกับที่ Admin เชิญ
