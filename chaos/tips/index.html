License Error / ไม่พบ License

เนื่องจาก License Error เกิดได้จากหลายสาเหตุ ลองวิธีเหล่านี้

สาเหตุและวิธีแก้ไข

  • ล็อกอินใหม่
    • อีเมลที่คุณใช้อาจไม่ได้รับการมอบหมายใบอนุญาต
    • โปรดเช็คกับผู้ดูแลใบอนุญาตของคุณก่อน
    • Sign out → Sign in ใหม่ด้วยอีเมลและรหัสผ่าน
  • เช็ค Chaos Services
    • ไปที่ Start Windows หรือพิม Startup apps
    • ไปที่ Settings → Apps → Starup
    • มองหาที่มีชื่อชื่อ Chaos ต้องเปิดอยู่ทั้งหมด
    • Sign out → Sign in ใหม่ด้วยอีเมลและรหัสผ่าน
  • รีสตาร์ท Chaos Services
    • ไปที่ Start Windows
    • ไปที่ Chaos
    • มองหาที่มีชื่อชื่อ Chaos
    • คลิก Start Service ทุกตัวเช่น Chaos Unified Login และ Chaos Cosmos
  • อัพเดตเป็นเวอร์ชั่นล่าสุด
    • ไปที่ Download
    • โปรดลบ License Server ออกก่อนการอัพเดต หากเวอร์ชั่นซอพแวร์ของคุณเก่าเกินไป
    • ติดตั้งและทดสอบอีกครั้ง
  • ตรวจสอบสิทธิ์ใบอนุญาต
    • ไปที่ my.chaos.com/products
    • ตรวจสอบว่าอีเมลของคุณมีสิทธิ์ใช้งานโปรดักส์ที่ต้องการ
    • หากไม่มี ให้ Admin เพิ่มสิทธิ์ผ่าน Organization Portal
  • ตรวจสอบว่า Chaos License Server ทำงานอยู่(สำหรับ V-Ray, Corona หรือ Enscape เวอร์ชั่นก่อนหน้า)
    • เปิด Browser แล้วไปที่ http://localhost:30304
    • หากหน้าไม่โหลด แสดงว่า Chaos License Server ไม่ทำงาน
    • ไปที่ Windows Services → ค้นหา Chaos License Server → คลิก Start
  • Reinstall Chaos License Server(สำหรับ V-Ray, Corona หรือ Enscape เวอร์ชั่นก่อนหน้า)
    • ลบ Chaos License Server
    • ดาวน์โหลดและติดตั้งใหม่จาก my.chaos.com/download/products
    • Sign in ใหม่ที่ http://localhost:30304

Chaos Unified Login, Chaos Cosmos หรือ Chaos License Server ต้องทำงานอยู่ตลอดเวลาที่ใช้งานโปรแกรม อย่า Disable หรือ Stop Service นี้

วิธีเช็ควันหมดอายุ

Admin สามารถตรวจสอบวันหมดอายุของใบอนุญาตทั้งหมดได้จาก Chaos Portal

ตรวจสอบวันหมดอายุ (Admin)

  • ไปที่ my.chaos.com/organization/licenses
  • เข้าสู่ระบบด้วยอีเมลที่ใช้สั่งซื้อ
  • เลือกเมนู Organization
  • วันหมดอายุและโปรดักส์จะแสดงอยู่ในหน้านี้

ตรวจสอบวันหมดอายุ (User)

  • ไปที่ my.chaos.com/products
  • เข้าสู่ระบบด้วยอีเมลผู้ใช้งาน
  • รายการโปรดักส์และวันหมดอายุจะแสดงในหน้านี้

หรือดูได้จาก Chaos License Server ที่ http://localhost:30304 → เมนู Online licensing

วิธีเปลี่ยนอีเมลผู้ใช้งาน

การเปลี่ยนอีเมลผู้ใช้งานทำโดย Admin โดยต้องถอดสิทธิ์อีเมลเดิมออกก่อน แล้วเพิ่มอีเมลใหม่เข้าไปในระบบ

ถอดสิทธิ์ผู้ใช้งานเดิม

  • ไปที่ my.chaos.com/organization/licenses
  • เข้าสู่ระบบด้วยอีเมลที่ใช้สั่งซื้อ
  • เลือกเมนู Organization
  • คลิกที่จุดสามจุด ⋮ ด้านหลังอีเมลผู้ใช้งานเดิม
  • เลือก Remove user → ยืนยัน

เพิ่มผู้ใช้งานใหม่

  • ที่หัวข้อ User คลิกที่จุดสามจุด ⋮ → Invite users
  • ใส่อีเมลผู้ใช้งานใหม่ → คลิก Invite
  • คลิก Back to Organization
  • คลิกทำเครื่องหมาย เลือกอีเมลใหม่ → เมนูด้านล่างเลือก Product → Assign
  • เลือกโปรดักส์ → Continue → ยืนยัน Assign
  • ผู้ใช้งานใหม่จะได้รับอีเมลคำเชิญ โปรดสร้างบัญชีหรือ Sign in เพื่อรับสิทธิ์

ผู้ใช้งานใหม่ต้องมีบัญชี Chaos ก่อน หากยังไม่มีให้สร้างที่ accounts.chaos.com/register

ข้อมูลเพิ่มเติม

  • คำถามที่พบบ่อย
  • วิธีจัดการใบอนุญาต Named License
  • วิธีจัดการใบอนุญาต Floating License
  • วิธีถอนใบอนุญาต (Deactivate)
