จัดการใบอนุญาต — Named License

Named License ผูกใบอนุญาตกับอีเมลผู้ใช้งานแต่ละคน — Admin ต้อง Assign โปรดักส์ให้อีเมลผู้ใช้งานแต่ละคนก่อนจึงจะเปิดใช้งานได้

ขั้นตอนเพิ่มอีเมลผู้ใช้งาน

  • ไปที่ my.chaos.com/organization/licenses
  • เข้าสู่ระบบด้วยอีเมลที่ใช้สั่งซื้อ
    • หากไม่มีบัญชีให้ Create Account
  • เมนูด้านบนเลือก Organization
  • ที่หัวข้อ User คลิกที่จุดสามจุด ⋮ → Invite users
  • ใส่อีเมลของผู้ใช้งานให้ครบตามจำนวน
  • คลิก Back to Organization เพื่อกลับไปหน้าก่อน
  • เลื่อนลงมาด้านล่าง จะมีอีเมลผู้ใช้งานแสดงอยู่
  • คลิกทำเครื่องหมาย เลือกอีเมลที่ต้องการ Assign
  • ที่เมนูด้านล่างเลือก Product → Assign
  • คลิก Continue with…users
  • เลือกโปรดักส์ → Continue
  • คลิกที่ชื่อโปรดักส์ → Continue with…products
  • ตรวจสอบข้อมูลสรุป → คลิก Assign to…users
  • เสร็จสิ้น คลิก Got it
  • กลับมาที่หน้าหลัก จะมีข้อมูลสรุปสำหรับอีเมลผู้ใช้งานและโปรดักส์ที่ใช้งานได้

ผู้ใช้งานจะได้รับอีเมลคำเชิญเพื่อเริ่มต้นใช้งานโปรแกรม — ผู้ใช้งานจะต้องมีบัญชี Chaos เพื่อเริ่มต้นใช้งาน

จัดการใบอนุญาต — Floating License

Floating License ใช้พร้อมกันได้ตามจำนวนที่ซื้อ โดยมี 2 รูปแบบ คือ ใช้อีเมลเดียวกันทุกเครื่อง หรือแยกอีเมลสำหรับผู้ใช้แต่ล่ะเครื่อง Floating License Sharing

แบบที่ 1 — ใช้อีเมลเดียวกันทุกเครื่อง

  • ไปที่ my.chaos.com/products
  • เข้าสู่ระบบด้วยอีเมลที่ใช้สั่งซื้อ
  • คุณจะพบกับใบอนุญาตทั้งหมด — ใช้อีเมลและรหัสผ่านนี้เปิดใช้งานทุกเครื่องได้เลย

แบบที่ 2 — แยกอีเมลสำหรับผู้ใช้แต่ล่ะเครื่อง

  • ทำตามขั้นตอน Named License เพื่อเพิ่มและ Assign อีเมลผู้ใช้งานแต่ละคน
    • ไม่ต้องเพิ่มโปรดักส์ให้ผู้ใช้งาน
  • ผู้ใช้งานแต่ละคนจะใช้อีเมลของตนเองเปิดใช้งาน โดยแชร์จำนวน Floating ร่วมกัน
  • โปรดดูให้มั่นใจว่า Floating license sharing ต้องมีสถานะ Enabled

หากใช้งานพร้อมกันเกินจำนวน Floating License ที่ซื้อ ผู้ใช้งานคนนั้นจะไม่สามารถเปิดใช้งานได้จนกว่าคนอื่นจะปิดโปรแกรม

ติดตั้งและเปิดใช้งาน Corona

ต้องติดตั้งโปรแกรม host เช่น 3ds Max หรือ Cinema 4D ก่อน — ไฟล์ติดตั้ง Corona สำหรับแต่ละ host จะใช้ไฟล์แยกกัน

ขั้นตอนติดตั้ง Corona

  • ดาวน์โหลดไฟล์ติดตั้ง Corona ที่หน้า ดาวน์โหลด
  • ดับเบิลคลิกที่ไฟล์ เพื่อติดตั้งโปรแกรม
  • คลิกทำเครื่องหมายที่ช่อง I accept… → คลิก Install
  • รอติดตั้งสักครู่ → คลิก Done

ขั้นตอนเปิดใช้งาน Chaos Corona

  • เปิดหน้าต่าง Render Setup (F10)
  • ไปที่แท็บ System
  • คลิก About Chaos Corona / Licensing
  • คลิกปุ่ม Sign In to Chaos Account
  • ระบบจะเปิด Web Browser ขึ้นมา ให้กรอก Email และ Password ของ Chaos Account

ติดตั้งและเปิดใช้งาน Enscape

ต้องติดตั้งโปรแกรม host ก่อน เช่น SketchUp, Revit, Rhino, Archicad หรือ Vectorworks — ไฟล์ติดตั้งเดียวรองรับทุก host

ขั้นตอนติดตั้ง Enscape

  • ดาวน์โหลดไฟล์ติดตั้ง Enscape ที่หน้า ดาวน์โหลด
  • ดับเบิลคลิกที่ไฟล์ เพื่อติดตั้งโปรแกรม
  • คลิกทำเครื่องหมายที่ช่อง I accept… → คลิก Next
  • คลิก Install → รอติดตั้งสักครู่ → คลิก Done

ขั้นตอนเปิดใช้งาน Chaos Enscape

  • ไปที่แถบเครื่องมือ (Toolbar) ของ Enscape ในโปรแกรมที่คุณใช้งาน
  • คลิกที่ปุ่มหรือเมนู Chaos Account
    • บางโปรแกรมจะอยู่ในเมนู Extensions → Enscape → Chaos Account
  • ระบบจะเปิด Web Browser ขึ้นมา ให้กรอก Email และ Password ของ Chaos Account

ติดตั้งและเปิดใช้งาน V-Ray

ต้องติดตั้งโปรแกรม host ก่อน เช่น SketchUp หรือ 3ds Max — สำหรับ V-Ray for 3ds Max ต้องใช้ไฟล์ติดตั้งที่ตรงกับเวอร์ชั่นของ 3ds Max เท่านั้น

ขั้นตอนติดตั้ง V-Ray

  • ดาวน์โหลดไฟล์ติดตั้ง V-Ray ที่หน้า ดาวน์โหลด
  • ดับเบิลคลิกที่ไฟล์ เพื่อติดตั้งโปรแกรม
  • คลิกทำเครื่องหมายที่ช่อง I accept… → คลิก Continue
  • คลิก Install → รอติดตั้งสักครู่ → คลิก Done

ขั้นตอนเปิดใช้งาน Chaos V-Ray

  • SketchUp / Rhino: ไปที่เมนู Extensions → V-Ray → Help → Chaos Account → เลือก Sign In
    • หรือคลิกที่ไอค่อนเครื่องมือรูปกาน้ำ
  • 3ds Max / Maya: ไปที่เมนู V-Ray ด้านบนสุด → Licensing → Chaos Account → เลือก Sign In
  • ระบบจะเปิด Web Browser ขึ้นมา ให้กรอก Email และ Password ของ Chaos Account

ถอนใบอนุญาต (Deactivate)

แนะนำให้ถอนใบอนุญาตก่อน Uninstall โปรแกรม หรือก่อนเปลี่ยนเครื่องคอมพิวเตอร์

ปัจจุบัน Chaos ใช้ตัวจัดการใบอนุญาต 2 แบบ ขึ้นอยู่กับเวอร์ชั่นแอปพลิเคชันของคุณ

ขั้นตอน Deactivate สำหรับ License Server

  • ไปที่ localhost:30304
  • ที่เมนูด้านบนคลิก Online licensing
  • คลิก Sign out
  • คลิก Yes เพื่อยืนยัน
  • หน้าจอแสดงข้อความ Sign out complete. — เสร็จเรียบร้อย

คุณสามารถใช้อีเมลและรหัสผ่านเดิมในการเปิดใช้งานที่คอมพิวเตอร์เครื่องใหม่ได้ทันที

ขั้นตอน Deactivate สำหรับ Cloud Licensing

  • Chaos Corona
    • 3ds Max: ไปที่หน้าต่าง Render Setup (F10) → แท็บ System → คลิกปุ่ม About Chaos Corona / Licensing → คลิก Chaos Account แล้วเลือก Sign Out
    • Cinema 4D: ไปที่เมนูด้านบน Corona → เลือก About → คลิก Chaos Account แล้วเลือก Sign Out
  • Enscape
    • ไปที่แถบเครื่องมือของ Enscape ในโปรแกรมที่คุณใช้งาน (เช่น SketchUp, Revit, Rhino)
    • หาเมนู Chaos Account (หรือในบางเวอร์ชันเข้าไปที่ Extensions/Enscape → Chaos Account)
    • คลิก Sign Out
  • V-Ray
    • SketchUp: ไปที่ Extensions → V-Ray → Help → Chaos Account → Sign Out
    • 3ds Max / Maya: ไปที่เมนู V-Ray ด้านบน → Licensing → Chaos Account → Sign Out

คุณสามารถใช้อีเมลและรหัสผ่านเดิมในการเปิดใช้งานที่คอมพิวเตอร์เครื่องใหม่ได้ทันที
