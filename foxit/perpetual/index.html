คำถามที่พบบ่อย

Perpetual คือใบอนุญาตแบบ ซื้อขาด จ่ายครั้งเดียว โดยไม่มีค่าสมัครสมาชิกรายปี เหมาะสำหรับผู้ที่ต้องการใช้งานโปรแกรมในระยะยาว แต่จะไม่สามารถอัพข้ามเวอร์ชั่นได้

เงื่อนไขคือ 1 License ต่อ 1 เครื่อง อย่างไรก็ตาม ใน 1 คำสั่งซื้ออาจมีหลาย Seat ขึ้นอยู่กับจำนวนที่สั่งซื้อ เช่น สั่งซื้อ 5 Licenses จะสามารถใช้ License Key เดียวกันเปิดใช้งานได้ทั้ง 5 เครื่อง

ไม่ได้ หากสั่งซื้อเวอร์ชัน Windows จะสามารถใช้งานได้บนคอมพิวเตอร์ Windows เท่านั้น ไม่สามารถนำไปใช้กับ Mac ได้ และในทางกลับกัน

ไปที่ ขั้นตอนติดตั้งและเปิดใช้งาน

ใช่ ต้อง Deactivate ก่อนทุกครั้ง เมื่อต้องการ Uninstall หรือเปลี่ยนเครื่อง เพื่อให้ License พร้อมนำไปใช้งานบนเครื่องใหม่ได้

เปิดโปรแกรม Foxit → ไปที่เมนู Help → คลิก Deactivate โปรดตรวจสอบเวอร์ชันและ License Key ให้ถูกต้องก่อนทำการ Deactivate ทุกครั้ง
