จัดการใบอนุญาต

วิธีจัดการใบอนุญาต

เมื่อสั่งซื้อสำเร็จคุณจะได้รับอีเมลยืนยันการสั่งซื้อ อีเมลที่สั่งซื้อสามารถเพิ่มอีเมลผู้ใช้งานและจัดการใบอนุญาตทั้งหมด

การใช้งานกำหนดให้ 1 ใบอนุญาต ผูกกับ 1 บัญชีอีเมล (เช่น หากมี 5 สิทธิ์การใช้งาน จะต้องใช้ 5 อีเมล) ทั้งนี้ อีเมลที่ใช้สั่งซื้อจะได้รับสิทธิ์เป็น ผู้ดูแลระบบ (Admin) ซึ่งสามารถจัดการมอบสิทธิ์ หรือโอนย้ายสิทธิ์การใช้งานให้แก่อีเมลอื่น ๆ ได้ตลอดเวลา โดยที่ยังคงสถานะผู้ดูแลระบบไว้ตามเดิม

ขั้นตอน จัดการใบอนุญาต

  • ไปที่ Admin Console หรือ ไปที่ Set Password เพื่อตั้งรหัสผ่าน
  • Sign in ด้วย อีเมล ที่ใช้สั่งซื้อ
  • ที่เมนูด้านซ้ายคลิก User ID Management → คลิก Users
  • เมนูด้านบนไปที่ Invited users
  • เมนูด้านขวาไปที่ Invited users → คลิก Invited users
  • ใส่อีเมลผู้ใช้งาน
    • คุณสามารถเพิ่มอีเมลได้คราวละหลายอีเมลโดยเพิ่มเครื่องหมายอัฒภาค (;)​​
  • ทำเครื่องหมายที่ช่อง Assign License เพื่อเพิ่มโปรดักส์
  • กด Save เพื่อบันทึก
  • คุณสามารถไปที่เมนู License Management เพื่อตรวจสอบผู้ใช้งานทั้งหมด
  • ผู้ใช้งานจะได้รับคำเชิญเพื่อเริ่มใช้งานทางอีเมล

Note: ผู้ใช้งานจะต้องกดรับคำเชิญทางอีเมลเพื่อเริ่มต้นใช้งานโปรแกรม (คำเชิญจะหมดอายุใน 3 วัน)

ติดตั้งและเปิดใช้งาน

คำเชิญมีอายุ 3 วันหลังจากที่ผู้ใช้งานได้รับอีเมล - หากคำเชิญหมดอายุโปรดแจ้งแอดมินของคุณเพื่อส่งคำเชิญใหม่

ขั้นตอนติดตั้งและเปิดใช้งาน

  • ผู้ใช้งานจะได้รับอีเมลคำเชิญจาก Foxit
  • คลิก Click here to join now!
  • ใส่ข้อมูลและตั้งรหัสผ่าน สำหรับเข้าใช้งาน Foxit
  • คลิกที่นี่เพื่อ Download ไฟล์ติดตั้ง
  • คลิกที่ไฟล์เพื่อติดตั้งโปรแกรม
  • คลิก Next → I accept → Next
  • คลิก Install → รอสักครู่ → คลิก Finish
  • เลือก Sign in
  • Sign in ด้วยอีเมลและรหัสผ่านที่ตั้งไปก่อนหน้า
  • โปรแกรมจะร้องขอให้เปิดปิดใหม่เลือก Restart Now
  • โปรแกรมจะเปิดขึ้นมาใหม่เป็นอันเสร็จเรียบร้อย

ถอนใบอนุญาต Deactivate

โปรด Deactivate ก่อนเสมอเมื่อต้องการ Uninstall หรือเปลี่ยนเครื่อง เพื่อให้ License พร้อมใช้งานบนเครื่องใหม่

วิธีปิดใช้งานเพื่อลบโปรแกรมหรือย้ายเครื่อง

  • เปิดโปรแกรม Foxit
  • ไปที่เมนู Help
  • คลิก Manage
  • คลิกเครื่องหมาย กากบาท (X) ที่ด้านหลัง
  • ปิดหน้าต่าง
  • ที่มุมขวาบน คลิกที่ เครื่องหมายสามเหลี่ยมเล็ก
  • คลิก Sign Out
  • คลิก Yes เพื่อยืนยัน เป็นอันเสร็จเรียบร้อย
