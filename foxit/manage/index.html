Licenses

ใบอนุญาต Foxit PDF Editor - Perpetual

  • Foxit PDF Editor - Perpetual: ใน 1 คำสั่งซื้อ จะได้รับ 1 License Key
  • ตัวอย่างเช่น หากสั่งซื้อ 5 Licenses จะสามารถใช้ License Key เดียวกันในการเปิดใช้งานได้ทั้ง 5 เครื่อง
  • เงื่อนไขการใช้งาน: 1 License ต่อ 1 เครื่องคอมพิวเตอร์
  • หากสั่งซื้อเวอร์ชันสำหรับ Windows จะสามารถใช้งานได้บนคอมพิวเตอร์ Windows เท่านั้น (ไม่สามารถนำไปใช้กับ Mac ได้)

ติดตั้งและเปิดใช้งาน

Foxit PDF Editor - Perpetual จะเปิดใช้งานด้วย License Key และจะต้อง Deactivate ก่อนลบโปรแกรมทุกครั้ง

ขั้นตอน ติดตั้ง

  • Download ไฟล์ติดตั้ง Foxit Editor
  • ดับเบิลคลิกที่ไฟล์ เพื่อติดตั้งโปรแกรม → คลิก Next
  • คลิกทำเครื่องหมาย ที่ช่องข้อความ I accept... → คลิก Next
  • คลิก Install → เมื่อติดตั้งสำเร็จ คลิก Finish

ขั้นตอนการเปิดใช้งาน

  • เปิดโปรแกรม Foxit
  • คลิก Activate
  • ใส่ License Key
  • คลิก Activate
  • หน้าจอแสดงข้อความ You have successfully...
  • เสร็จสิ้นขั้นตอนการติดตั้งและเปิดใช้งาน Foxit PDF Editor - Perpetual

Note: 1 License Key อาจมีหลาย Seat(s) ขึ้นอยู่กับออเดอร์ที่คุณสั่งซื้อ

ถอนใบอนุญาต Deactivate

ต้อง Deactivate ก่อนเสมอเมื่อต้องการ Uninstall หรือเปลี่ยนเครื่อง เพื่อให้ License พร้อมใช้งานบนเครื่องใหม่

โปรดเช็คเวอร์ชั่นและ License Key ให้ถูกต้อง ก่อน Deactivate

วิธีปิดใช้งานเพื่อลบโปรแกรมหรือย้ายเครื่อง

  • เปิดโปรแกรม Foxit
  • ไปที่เมนู Help
  • คลิก Deactivate
