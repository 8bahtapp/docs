คำถามที่พบบ่อย

Subscription คือใบอนุญาตแบบ รายปี โดยผูกสิทธิ์การใช้งานกับบัญชีอีเมลแทนการใช้ License Key และมักอัปเดตเวอร์ชันใหม่อยู่เสมอตลอดอายุสมาชิก

1 ใบอนุญาต ผูกกับ 1 บัญชีอีเมล เช่น หากมี 5 สิทธิ์ต้องใช้ 5 อีเมล โดยอีเมลที่ใช้สั่งซื้อจะได้รับสถานะ Admin สามารถมอบหรือโอนสิทธิ์ให้ผู้ใช้งานอื่นได้

เข้าสู่ระบบที่ Foxit Admin Console ข้อมูลเพิ่มเติมไปที่ การจัดการใบอนุญาต

คลิก Click here to join now! ในอีเมลคำเชิญ ตั้งรหัสผ่านสำหรับบัญชี Foxit จากนั้นดาวน์โหลดและติดตั้งโปรแกรม แล้ว Sign in ด้วยอีเมลและรหัสผ่านที่ตั้งไว้ โปรแกรมจะ Restart และพร้อมใช้งาน

คำเชิญมีอายุ 3 วัน หากหมดอายุให้แจ้ง Admin เพื่อส่งคำเชิญใหม่ผ่าน Foxit Admin Console อีกครั้ง

ใช่ ควร Deactivate ก่อนทุกครั้ง เพื่อให้สิทธิ์การใช้งานพร้อมนำไปใช้งานบนเครื่องใหม่ได้

เปิดโปรแกรม Foxit → ไปที่เมนู Help → Manage → คลิกเครื่องหมาย กากบาท (X) ด้านหลัง → ปิดหน้าต่าง → ที่มุมขวาบนคลิก เครื่องหมายสามเหลี่ยมเล็ก → Sign Out → Yes เพื่อยืนยัน

โปรดไปที่ Open Ticket เจ้าหน้าที่จะติดต่อคุณในช่วงเวลาทำการ
