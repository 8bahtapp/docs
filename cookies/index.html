ภาพรวม

นโยบายนี้อธิบายวิธีที่ผู้ดำเนินการ 8Baht Docs ใช้คุกกี้และเทคโนโลยีติดตามที่คล้ายกันบนเว็บไซต์

  • นโยบายนี้เป็นส่วนหนึ่งของนโยบายความเป็นส่วนตัว (Privacy Policy)
  • การใช้งานเว็บไซต์ต่อไปหลังจากได้รับแจ้ง ถือว่าคุณรับทราบการใช้คุกกี้ตามนโยบายนี้
  • คุณสามารถเพิกถอนความยินยอมได้ตลอดเวลาผ่านการตั้งค่าเบราว์เซอร์หรือแบนเนอร์คุกกี้

คุกกี้คืออะไร

  • คุกกี้คือไฟล์ข้อความขนาดเล็กที่ถูกบันทึกลงในอุปกรณ์ของคุณ (คอมพิวเตอร์ แท็บเล็ต หรือสมาร์ทโฟน) เมื่อเข้าชมเว็บไซต์
  • คุกกี้ช่วยให้เว็บไซต์จดจำการตั้งค่า ความชอบ และพฤติกรรมการใช้งานของคุณระหว่างการเข้าชมแต่ละครั้ง
  • คุกกี้แบ่งเป็น Session Cookie (หมดอายุเมื่อปิดเบราว์เซอร์) และ Persistent Cookie (คงอยู่ตามระยะเวลาที่กำหนด)
  • คุกกี้ไม่สามารถรันโปรแกรม ส่งไวรัส หรือเข้าถึงไฟล์ในอุปกรณ์ของคุณได้

ประเภทคุกกี้ที่เราใช้

1. คุกกี้ที่จำเป็น (Strictly Necessary Cookies)

  • วัตถุประสงค์: จำเป็นสำหรับการทำงานพื้นฐานของเว็บไซต์ ไม่สามารถปิดได้
  • ข้อมูลที่เก็บ: การตั้งค่าความยินยอมคุกกี้ของคุณ (ยอมรับ / ปฏิเสธ)
  • ที่เก็บ: localStorage ในเบราว์เซอร์ของคุณ
  • ฐานทางกฎหมาย: ประโยชน์อันชอบธรรม (Legitimate Interest)

2. คุกกี้เพื่อการวิเคราะห์ (Analytics Cookies)

  • วัตถุประสงค์: ช่วยให้เราเข้าใจว่าผู้ใช้งานโต้ตอบกับเว็บไซต์อย่างไร เพื่อปรับปรุงประสบการณ์การใช้งาน
  • ข้อมูลที่เก็บ: จำนวนผู้เข้าชม หน้าที่ได้รับความนิยม เวลาที่ใช้บนเว็บไซต์ การเลื่อนหน้าจอ การคลิก และ Session Recording
  • ลักษณะข้อมูล: ข้อมูลทั้งหมดเป็นแบบ Pseudonymous ไม่สามารถระบุตัวตนได้โดยตรง
  • ฐานทางกฎหมาย: ความยินยอม (Consent) — คุณสามารถปฏิเสธได้

หากคุณปฏิเสธคุกกี้เพื่อการวิเคราะห์ เว็บไซต์ยังใช้งานได้ปกติทุกฟีเจอร์ เพียงแต่เราจะไม่สามารถเก็บข้อมูลการใช้งานของคุณเพื่อปรับปรุงบริการได้

Microsoft Clarity

  • ผู้ให้บริการ: Microsoft Corporation
  • วัตถุประสงค์: วิเคราะห์พฤติกรรมผู้ใช้งาน เช่น Heatmap, Session Recording และ Click Tracking
  • ข้อมูลที่ส่งให้บุคคลที่สาม: IP Address (แบบย่อ), User Agent, URL ที่เยี่ยมชม, การโต้ตอบกับหน้าเว็บ
  • การเก็บข้อมูล: เซิร์ฟเวอร์ของ Microsoft อาจอยู่นอกประเทศไทย

  • วิธีปฏิเสธ: clarity.microsoft.com/optout

เราไม่ใช้คุกกี้เพื่อโฆษณา (Advertising Cookies) หรือแบ่งปันข้อมูลส่วนบุคคลให้บุคคลที่สามเพื่อวัตถุประสงค์ทางการตลาด

ฐานทางกฎหมาย

  • เราดำเนินการภายใต้ พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)
  • คุกกี้ที่จำเป็น ใช้ฐาน Legitimate Interest เนื่องจากจำเป็นต่อการทำงานของเว็บไซต์
  • คุกกี้เพื่อการวิเคราะห์ ใช้ฐาน Consent โดยเราจะขอความยินยอมก่อนเสมอ
  • คุณมีสิทธิ์เพิกถอนความยินยอมได้ตลอดเวลา โดยไม่กระทบสิทธิ์ที่ได้รับก่อนหน้า

ระยะเวลาเก็บข้อมูล

  • การตั้งค่าความยินยอม (localStorage): คงอยู่จนกว่าคุณจะลบ cookies ในเบราว์เซอร์
  • Microsoft Clarity: เก็บข้อมูล Session สูงสุด 13 เดือน ตามนโยบายของ Microsoft
  • เมื่อครบกำหนด ข้อมูลจะถูกลบหรือทำให้เป็นข้อมูลนิรนามโดยอัตโนมัติ

การจัดการคุกกี้

ผ่านเว็บไซต์นี้

  • เมื่อเข้าเว็บไซต์ครั้งแรก จะมีแบนเนอร์ให้เลือกยอมรับหรือปฏิเสธคุกกี้
  • หากต้องการเปลี่ยนการตั้งค่า ให้ลบ cookies ในเบราว์เซอร์แล้วรีโหลดหน้าเพื่อแสดงแบนเนอร์อีกครั้ง

ผ่านเบราว์เซอร์

  • Chrome — Settings → Privacy and Security → Cookies and other site data
  • Firefox — Settings → Privacy & Security → Cookies and Site Data
  • Safari — Preferences → Privacy → Manage Website Data
  • Edge — Settings → Cookies and site permissions → Manage and delete cookies

การบล็อกคุกกี้ทั้งหมดผ่านเบราว์เซอร์อาจทำให้บางส่วนของเว็บไซต์ทำงานผิดปกติ เนื่องจากคุกกี้ที่จำเป็นถูกบล็อกไปด้วย

  • สิทธิ์ในการแก้ไข: คุณสามารถขอให้แก้ไขข้อมูลที่ไม่ถูกต้อง
  • สิทธิ์ในการลบ: คุณสามารถขอให้ลบข้อมูลส่วนบุคคลของคุณ

  • สิทธิ์ในการคัดค้าน: คุณสามารถคัดค้านการประมวลผลข้อมูลในบางกรณี
