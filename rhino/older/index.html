คำถามที่พบบ่อย

จัดการใบอนุญาต Rhino Cloud Zoo ได้ที่ Rhino License Portal โดย Sign in ด้วยอีเมลที่ใช้สร้างทีม (Cloud Zoo)

หลังสั่งซื้อจะได้รับ License Key (ขึ้นต้นด้วย RH80…) นำไปเพิ่มใน Cloud Zoo Team ที่ Rhino License Portal จากนั้นผู้ใช้งานสามารถเปิดโปรแกรมแล้ว Sign in ด้วยอีเมลได้เลย ดูคู่มือที่ วิธีจัดการใบอนุญาต

แนะนำให้เชื่อมต่ออินเทอร์เน็ตเพื่อใช้งาน Rhino Cloud Zoo อย่างต่อเนื่อง แต่สามารถใช้งานแบบออฟไลน์ได้ชั่วคราวหลังจาก Sign in ครั้งแรกแล้ว

Cloud Zoo คือระบบ License บนคลาวด์ที่ใช้อีเมลเปิดใช้งานซึ่งสะดวกกับการจัดการมากกว่า ส่วน Single-Computer จะผูกใบอนุญาตกับเครื่องเพียงเครื่องเดียว

โดยค่าเริ่มต้น Rhino Account จะใช้การยืนยันทางอีเมลแทนรหัสผ่าน หากต้องการตั้งรหัสผ่านดูคู่มือที่ วิธีตั้งรหัสผ่าน

ไปที่ Rhino Accounts เลือก Login → Password แล้วรีเซ็ตรหัสผ่านใหม่ หรือใช้วิธีกดยืนยันทางอีเมลแทนได้เลย

ลอง Logout ออกจากโปรแกรมด้วย Command Logout แล้ว Sign in ใหม่ หากยังติดปัญหาให้ตรวจสอบว่า License Key ถูกเพิ่มใน Cloud Zoo Team แล้ว หรือ ติดต่อเจ้าหน้าที่

ได้ Rhino รองรับทั้ง Windows และ macOS โดยใช้อีเมลและ License เดียวกัน ไม่ต้องซื้อแยก

ซอฟต์แวร์ Rhino เป็นสัญญาอนุญาตสิทธิ์แบบซื้อขาด (Perpetual License) จึงไม่มีวันหมดอายุ ทั้งนี้ สำหรับนโยบายการอัปเดตเวอร์ชันและการสนับสนุนหลังการขาย (Support) จะเป็นไปตามเงื่อนไขที่กำหนดโดยผู้พัฒนา (Robert McNeel & Associates) โดยตรง

การอัปเดตย่อย: สามารถอัปเดตเพื่อแก้ไขข้อบกพร่องและเพิ่มฟีเจอร์ภายในเวอร์ชันหลักเดิมได้ ฟรี เช่น 8.1 เป็น 8.2

การอัปเกรดเวอร์ชันใหม่: หากต้องการเปลี่ยนเป็นเวอร์ชันหลักถัดไป (เช่น อัปเกรดจาก Rhino 7 เป็น Rhino 8) จะมีค่าใช้จ่ายในการซื้อสิทธิ์อัปเกรดในราคาพิเศษ
