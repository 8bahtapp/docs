วิธีจัดการใบอนุญาต

คุณสามารถเลือกวิธีการเปิดใช้งาน Rhino ได้ 3 วิธี ได้แก่ Cloud Zoo, Single-Computer, และ LAN Zoo - อย่างใดอย่างหนึ่ง
Cloud Zoo เป็นวิธีที่ยืดหยุ่นที่สุดสำหรับการจัดการและเปิดใช้งาน Rhino

คุณสามารถใช้อีเมลและรหัสผ่านเดียวกันสำหรับทุกเครื่องเมื่อใช้ Cloud Zoo

ขั้นตอนการทำ Cloud Zoo for Teams

  • ไปที่หน้าจัดการใบอนุญาต Rhino License Portal
  • เข้าสู่ระบบด้วยอีเมลที่ต้องการ (อาจเป็นอีเมลกลางหรือของไอที)
    • หากยังไม่มีบัญชีโปรด Create account
  • เลือกเมนู Manage your licenses เพื่อเข้าสู่หน้าจัดการใบอนุญาต
  • คลิก Create a New Team… เพื่อสร้างทีม
  • ตั้งชื่อทีม → คลิก Create a New Team
    • ส่วนของ Description สามารถเว้นไว้ได้
  • คลิก Add License
  • ใส่ข้อมูล License Key → คลิก Add License
    • License Key จะขึ้นต้นด้วย RH80…
    • สามารถทำซ้ำขั้นตอนเดิมในกรณีมีมากกว่า 1 License
  • เสร็จสิ้น — คุณสามารถเริ่มใช้งาน Rhino ด้วยการ Sign in ด้วยอีเมลได้เลย

โดยค่าเริ่มแรก Rhino จะใช้วิธีกดยืนยันทางอีเมลเพื่อเข้าสู่ระบบ คุณสามารถเปลี่ยนเป็นรหัสผ่านได้ที่ วิธีตั้งรหัสผ่าน

ติดตั้งและเปิดใช้งาน

ขั้นตอนนี้สำหรับการเปิดใช้งานแบบ Cloud Zoo แนะนำให้เชื่อมต่ออินเทอร์เน็ตระหว่างใช้งาน

ขั้นตอนติดตั้งและเปิดใช้งาน Rhino Cloud Zoo

  • ดาวน์โหลดไฟล์ติดตั้ง Rhino ที่หน้า ดาวน์โหลด
  • ดับเบิลคลิกที่ไฟล์ เพื่อติดตั้งโปรแกรม → คลิก Install Now
  • รอติดตั้งสักครู่ → คลิก Close
  • คลิก Install
  • เปิดโปรแกรม Rhino
  • คลิกทำเครื่องหมายที่ช่อง ยอมรับข้อตกลงการใช้งาน
  • เลือก Options → เลือก Login
  • Rhino จะเปิด Web Browser ขึ้นมาเพื่อเข้าสู่ขั้นตอน Login
  • เข้าสู่ระบบด้วยอีเมลที่ผูกกับ Cloud Zoo Team
  • หน้าจอแสดงข้อความ Login completed. Please go back to Rhino.
  • กลับไปที่โปรแกรม Rhino — สามารถใช้งานได้เลย

หากเข้าสู่ระบบแล้วไม่พบ License ให้ตรวจสอบว่า License Key ถูกเพิ่มใน Cloud Zoo Team แล้ว หรือดูที่ วิธีจัดการใบอนุญาต

ถอนใบอนุญาต (Deactivate)

แนะนำให้ถอนใบอนุญาตก่อน Uninstall โปรแกรม หรือก่อนเปลี่ยนเครื่องคอมพิวเตอร์

วิธีถอนใบอนุญาต Cloud Zoo (Logout)

  • เปิดโปรแกรม Rhino
  • ใช้คำสั่ง Command Logout
  • กดปุ่ม Enter เพื่อยืนยัน
  • โปรแกรมจะทำการตรวจสอบและออกจากระบบ — เสร็จเรียบร้อย
  • คุณสามารถ Sign in ด้วยอีเมลเดิมที่เครื่องใหม่ได้ทันที

หากต้องการ Remove license จาก Single-computer หรือ LAN Zoo ดูคู่มือเพิ่มเติมที่ McNeel Wiki
