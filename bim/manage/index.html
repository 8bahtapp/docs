ติดตั้งและเปิดใช้งาน

คุณจะต้องติดตั้ง SketchUp ก่อนเพื่อติดตั้งปลั๊กอินเสริม

วิธีติดตั้งและเปิดใช้งาน BIM Bundle

  • Download ไฟล์ติดตั้ง
  • เปิดโปรแกรม SketchUp
  • ไปที่เมนู Extensions → Extension Manager
  • คลิกปุ่ม Install Extension
  • ไปที่โฟลเดอร์ที่มีไฟล์ติดตั้งนามสกุล .brz
  • คลิกที่ไฟล์ .brz จากนั้นคลิก Open

ขั้นตอนการเปิดใช้งาน (Activation)

  • ไปที่เมนู Extensions บนแถบเครื่องมือ SketchUp
  • เลือก Profile Builder หรือ Quantifier Pro → คลิก License..
  • คลิกปุ่ม Add License..
  • กรอกข้อมูล Email และ License Key ให้ถูกต้อง
  • คลิกปุ่ม Activate License.. เพื่อเริ่มใช้งาน
  • Note: ก่อนลบโปรแกรมหรือรีเซ็ตเครื่องคอมพิวเตอร์ใหม่ แนะนำให้ Deactivate ก่อนทุกครั้ง เพื่อป้องกันสิทธิ์เครื่องเต็ม

ถอนใบอนุญาต Deactivate

ต้อง Deactivate ก่อนเสมอเมื่อต้องการ Uninstall หรือเปลี่ยนเครื่อง เพื่อให้ License พร้อมใช้งานบนเครื่องใหม่

ขั้นตอนปิดใช้งาน Profile Builder/ Quantifier Pro

  • เปิดโปรแกรม SketchUp
  • ไปที่เมนู Extensions
  • เลือก Profile Builder/ Quantifier Pro
  • คลิก License..
  • คลิก Remove License..

วิธี Reset Activation

ขั้นตอนรีเซ็ตการเปิดใช้งาน

  • ไปที่เว็บไซต์ mind.sight.studios - My Licenses
  • Sign in เข้าสู่ระบบด้วยอีเมลที่เชื่อมโยงกับใบอนุญาต
  • หากยังไม่มีบัญชีผู้ใช้งาน ให้คลิก Create one! เพื่อสมัครสมาชิกก่อน
  • เมื่อเข้าสู่ระบบสำเร็จ คุณจะพบกับข้อมูลใบอนุญาตของคุณทั้งหมด
  • เลื่อนหน้าจอลงมาด้านล่างสุด
  • คลิกปุ่ม Reset All Activations
  • คลิกปุ่ม Submit เพื่อยืนยันการทำรายการ
  • เมื่อระบบขึ้นข้อความแสดงสำเร็จ "All licenses reset successfully!" เป็นอันเรียบร้อย
  • คุณสามารถนำ License Key ไปกรอกเปิดใช้งานบนเครื่องใหม่หรือเปิดใช้งานซ้ำได้อีกครั้งทันที
