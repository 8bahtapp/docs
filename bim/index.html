คำถามที่พบบ่อย

BIM Bundle ประกอบด้วย 2 โปรแกรม ได้แก่ Profile Builder และ Quantifier Pro ซึ่งเป็นปลั๊กอินเสริมสำหรับ SketchUp

คุณต้องติดตั้ง SketchUp ก่อนเสมอ เนื่องจาก Profile Builder และ Quantifier Pro เป็นปลั๊กอินที่ทำงานภายใน SketchUp

ดาวน์โหลดไฟล์ติดตั้ง (.rbz) จากนั้นเปิด SketchUp ไปที่ Extensions → Extension Manager คลิก Install Extension แล้วเลือกไฟล์ที่ดาวน์โหลดมา

เปิด SketchUp ไปที่เมนู Extensions เลือก Profile Builder หรือ Quantifier Pro แล้วคลิก License.. → Add License.. จากนั้นกรอก Email และ License Key ให้ถูกต้อง แล้วคลิก Activate License..

ใช่ แนะนำให้ Deactivate ก่อนทุกครั้ง เมื่อต้องการ Uninstall หรือเปลี่ยนเครื่อง เพื่อให้ License พร้อมนำไปใช้งานบนเครื่องใหม่ได้ทันที

เปิด SketchUp ไปที่เมนู Extensions เลือก Profile Builder หรือ Quantifier Pro คลิก License.. → Remove License.. เป็นอันเสร็จสิ้น

สามารถ Reset Activation ได้ที่เว็บไซต์ mind.sight.studios – My Licenses เข้าสู่ระบบด้วยอีเมลที่ผูกกับใบอนุญาต จากนั้นเลื่อนลงด้านล่างสุด แล้วคลิก Reset All Activations → Submit เมื่อขึ้นข้อความ "All licenses reset successfully!" สามารถนำ License Key กลับมาใช้งานได้ทันที
