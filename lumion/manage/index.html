Lumion Manage License

วิธีติดตั้งและเปิดใช้งาน Lumion Pro

โปรดตรวจสอบให้แน่ใจว่าคอมพิวเตอร์ของคุณเป็นไปตามข้อกำหนดขั้นต่ำของระบบ: Lumion System Requirements

ขั้นตอนจัดการใบอนุญาต Lumion Pro

  • ไปที่หน้าจัดการบัญชี Lumion Account
  • Sign in ด้วยอีเมลที่ใช้สั่งซื้อ (หากยังไม่มีบัญชีให้คลิก Create an account)
  • คลิกที่เมนู License Keys
  • คุณจะพบกับใบอนุญาตของคุณ
    • หากไม่พบใบอนุญาต โปรดคลิก Register a License Key และตรวจสอบให้มั่นใจว่าอยู่ในหัวข้อ Subscriptions
  • คลิกที่ไอคอน User (รูปคน)
  • โดยค่าเริ่มแรก ใบอนุญาตจะถูก Assign ไว้ที่แอดมิน ซึ่งสามารถใช้อีเมลแอดมินเข้าใช้งานได้ทันที
  • หากคุณมีมากกว่า 1 License จะต้องเพิ่มอีเมลผู้ใช้งานให้ครบตามจำนวน โดยคลิกที่ Assign user to license
  • ใส่อีเมลผู้ใช้งานใหม่ จากนั้นคลิก Confirm >> Ok (สามารถทำซ้ำขั้นตอนเดิมเพื่อเพิ่มอีเมลให้ครบตามจำนวน)

ขั้นตอนการติดตั้งและเปิดใช้งาน Lumion Pro

  • คลิกที่เมนู Licenses ด้านบนเพื่อกลับไปหน้าหลัก
  • คุณจะพบกับปุ่มสำหรับดาวน์โหลดไฟล์ติดตั้ง ให้คลิกที่ Download product Lumion เพื่อรับไฟล์
  • ดับเบิลคลิกที่ไฟล์ที่ดาวน์โหลดมา เพื่อเริ่มการติดตั้งโปรแกรม
  • โปรแกรมจะทำการดาวน์โหลดไฟล์ติดตั้งเพิ่มเติม (ขนาดประมาณ 105 GB)
  • เมื่อดาวน์โหลดเสร็จแล้ว ให้คลิก Start Installation
  • เปิดโปรแกรมและ Sign in เข้าสู่ระบบด้วยอีเมลผู้ใช้งานที่ได้รับสิทธิ์
  • เสร็จสิ้นขั้นตอนการติดตั้งและเปิดใช้งานพร้อมเริ่มทำงานได้ทันที

Note: โปรแกรม Lumion จำเป็นต้องมีการเชื่อมต่ออินเทอร์เน็ตตลอดเวลาในการเปิดใช้งานและตรวจสอบสิทธิ์ และคุณสามารถปลดสิทธิ์การใช้งานของ User เดิมได้โดยการคลิกที่ รูปถังขยะ ในหน้าจัดการใบอนุญาต

วิธีติดตั้งและเปิดใช้งาน Lumion Studio

โปรดตรวจสอบให้แน่ใจว่าคอมพิวเตอร์ของคุณเป็นไปตามข้อกำหนดขั้นต่ำของระบบ: Lumion System Requirements

ขั้นตอนติดตั้งและเปิดใช้งาน Lumion Studio

  • ไปที่หน้าจัดการบัญชี Lumion Account
  • Sign in ด้วยอีเมลที่ใช้สั่งซื้อ (หากยังไม่มีบัญชีให้คลิก Create an account)
  • คลิกที่เมนู License Keys
  • คุณจะพบกับใบอนุญาตของคุณ (หากไม่พบใบอนุญาตโปรดคลิก Register a License Key)
  • คลิกที่ปุ่ม Download product Lumion เพื่อรับไฟล์ติดตั้ง
  • ระบบจะแสดง Activation code สำหรับใช้ในการเปิดใช้งาน (โปรดคัดลอกเก็บไว้)
  • ดับเบิลคลิกที่ไฟล์ที่ดาวน์โหลดมา เพื่อเริ่มการติดตั้งโปรแกรม
  • กรอก Activation code ที่ได้จากระบบลงไป จากนั้นคลิก Verify
  • โปรแกรมจะทำการดาวน์โหลดไฟล์ติดตั้งเพิ่มเติม (ขนาดประมาณ 105 GB)
  • เมื่อดาวน์โหลดเสร็จสิ้น ให้คลิก Start Installation
  • เสร็จสิ้นขั้นตอนการติดตั้งและพร้อมใช้งานทันที

Note: โปรแกรม Lumion จำเป็นต้องมีการเชื่อมต่ออินเทอร์เน็ตในการเปิดใช้งานและตรวจสอบสิทธิ์ระหว่างการทำงาน

วิธีรีเซ็ตใบอนุญาต (Change/Reset License)

ในปัจจุบันคุณไม่จำเป็นต้องลบและติดตั้งโปรแกรม Lumion ใหม่เมื่อมีการเปลี่ยนแปลงใบอนุญาต โดยตั้งแต่เวอร์ชั่น Lumion 2025.0 ขึ้นไป คุณสามารถสั่งรีเซ็ตผ่านตัวโปรแกรมได้ทันที

ขั้นตอนรีเซ็ตใบอนุญาต สำหรับ Lumion 2025.0 ขึ้นไป

  • เปิดโปรแกรม Lumion ในฐานะผู้ดูแลระบบ (Run as administrator)
  • ไปที่เมนู การตั้งค่า (Settings)
  • เลือกหัวข้อ License
  • คลิกที่ปุ่ม Reset License
  • ทำการปิดและเปิดโปรแกรม Lumion ใหม่อีกครั้ง
  • ระบบจะแสดงหน้าต่างแจ้งให้คุณ เข้าสู่ระบบ (Sign in) หรือ ป้อนรหัสเปิดใช้งาน (Activation code) ใหม่อีกครั้งตามที่คุณต้องการ

Note: กรณีต้องการย้ายเครื่อง โปรแกรม Lumion สามารถย้ายไปที่เครื่องใหม่ได้เลยโดยใช้ข้อมูลใบอนญาตเดิม
