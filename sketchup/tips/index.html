วิธีรีเซ็ตใบอนุญาต (Deauthorize)

หากคุณเข้าสู่ระบบที่โปรแกรม SketchUp และมีข้อความแจ้งว่า "You have exceeded your allowed activations" หรือ "Please authorize SketchUp" โปรดดำเนินการตามขั้นตอนดังนี้เพื่อรีเซ็ตการเข้าสู่ระบบทั้งหมด

รีเซ็ตการเข้าสู่ระบบ (Deauthorize All)

  • คลิกที่ Manage Activations ในโปรแกรม หรือไปที่ SketchUp License Portal
  • เข้าสู่ระบบ
  • เลือกโปรไฟล์ชื่อบริษัท (Purchased via....)
  • เลือก My Products
  • คลิก View Included Applications
  • คลิก Manage Devices
  • คลิก Deauthorize All → คลิก Done
  • กลับไปที่โปรแกรม SketchUp
  • Sign out และ Sign in ใหม่อีกครั้ง

ขั้นตอนอาจมีแตกต่างเล็กน้อยขึ้นอยู่กับ Role ของคุณ

วิธีเปลี่ยนอีเมลผู้ใช้งาน

การเปลี่ยนอีเมลผู้ใช้งานทำโดย Admin โดยต้องถอดสิทธิ์อีเมลเดิมออกก่อน แล้วเพิ่มอีเมลใหม่เข้าไปในระบบ

ถอดสิทธิ์ผู้ใช้งานเดิม

  • ไปที่ SketchUp License Portal
  • เข้าสู่ระบบด้วยอีเมล Admin
  • เลือกโปรไฟล์ชื่อบริษัท (Purchased via....)
  • เลือก Members
  • คลิกที่ ⁝ (จุดสามจุด) ด้านหลังอีเมลผู้ใช้งาน
  • คลิก Modify Product Access
  • คลิกยกเลิกโปรดักส์
  • คลิกยืนยัน Save Product Access

เพิ่มผู้ใช้งานใหม่

  • เลือก Add New User เพื่อเพิ่มอีเมลผู้ใช้งาน
  • ใส่อีเมลผู้ใช้งาน → คลิก Next
  • เลือกโปรดักส์ SketchUp ที่ต้องการ และคลิก Add User
  • อีเมลจะถูกเพิ่มเข้ามาที่หน้าจัดการใบอนุญาต
  • ผู้ใช้งานใหม่ (Status: Invited) จะได้รับอีเมลคำเชิญจาก Trimble โปรดกดรับคำเชิญทางอีเมล

ผู้มีสิทธิ์ใช้งานจะมีสถานะ 1 Product... หากไม่ได้รับสิทธิ์จะเป็น None

วิธีเช็ควันหมดอายุ (Admin)

SketchUp Subscription สามารถเช็ควันหมดอายุได้แบบออนไลน์โดยผู้ดูแลใบอนุญาต (อีเมลที่ใช้สั่งซื้อหรือผู้ที่ได้รับสิทธิ์ Admin) โดยมีข้อมูลที่จำเป็นทั้งหมดสำหรับการต่ออายุ

ขั้นตอนสำหรับผู้ดูแลใบอนุญาต

  • ไปที่ SketchUp License Portal
  • เข้าสู่ระบบด้วยอีเมล Admin
  • เลือกโปรไฟล์ชื่อบริษัท (Purchased via....)
  • เลือก Plan Settings
  • วันหมดอายุ, ชื่อโปรดักส์ และจำนวนใบอนุญาตจะแสดงอยู่ที่หน้านี้

หน้านี้จะเห็นวันหมดอายุของใบอนุญาตทั้งหมด เฉพาะผู้ดูแลใบอนุญาตเท่านั้น — หากคุณเป็นผู้ใช้งานทั่วไป โปรดดู วิธีเช็ควันหมดอายุ (User)

วิธีเช็ควันหมดอายุ (User)

ผู้ใช้งานทั่วไปสามารถตรวจสอบวันหมดอายุของใบอนุญาตได้โดยตรงจากในโปรแกรม SketchUp

ขั้นตอนสำหรับผู้ใช้งาน

  • เปิดโปรแกรม SketchUp ของคุณ
  • วันหมดอายุของคุณจะแสดงที่มุมด้านบนทางขวา
  • หรือไปที่เมนู Help → Manage Licensing

หากคุณเป็นผู้ดูแลใบอนุญาต โปรดดู วิธีเช็ควันหมดอายุ (Admin)

วิธีบันทึกไฟล์เป็นเวอร์ชั่นเก่า

SketchUp 2024 หรือใหม่กว่าจะไม่มีเครื่องมือสำหรับ Save As ไฟล์เป็นเวอร์ชั่นเก่า คุณจะต้องใช้ Extension เพิ่มเติมเพื่อบันทึกไฟล์เป็นเวอร์ชั่นเก่า

ไฟล์ที่บันทึกด้วย SketchUp 2021 หรือใหม่กว่าสามารถใช้งานร่วมกันได้โดยไม่ต้องระบุเวอร์ชั่น

ติดตั้ง Extension — Dezmo Save to older SketchUp Version

  • ดาวน์โหลดไฟล์ติดตั้ง Dezmo ที่ Download - Dezmo Save to older SketchUp Version หรือที่ SketchUcation
  • คุณจะได้รับไฟล์ .rbz สำหรับติดตั้ง
  • เปิด SketchUp (เลือก Templates ใดก็ได้ หากมี)
  • ที่เมนูด้านบนเลือก Extension → Extension Manager
  • คลิก Install Extension
  • ไปที่โฟลเดอร์ไฟล์ .rbz ที่คุณดาวน์โหลดมา
  • คลิกที่ไฟล์ .rbz → คลิก Open
  • เครื่องมือ Dezmo จะแสดงขึ้นมา
    • หากไม่แสดงให้ไปที่เมนู View → Toolbars → เลือก Dezmo
  • คุณสามารถเลือกบันทึกเป็นเวอร์ชั่นที่ต้องการ

เนื่องจาก Extension ถูกพัฒนาโดยบุคคลที่สาม อาจมีข้อผิดพลาดในการใช้งาน
