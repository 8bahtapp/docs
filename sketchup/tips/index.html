วิธีรีเซ็ตการเข้าสู่ระบบ

ปัญหาเข้าสู่ระบบมีข้อความแจ้งว่า "You have exceeded your allowed activations" หรือ "Please authorize SketchUp" โปรดดำเนินการตามขั้นตอนดังนี้เพื่อรีเซ็ตการเข้าสู่ระบบ

ขั้นตอนรีเซ็ตการเข้าสู่ระบบสำหรับ SketchUp Subscription

  • คลิกที่ Manage Activations หรือไปที่ SketchUp License Portal
  • เข้าสู่ระบบ (หากมี)
  • เลือกโปรไฟล์ชื่อบริษัท (Purchased via....)
  • เลือก My Products
  • คลิกที่ View Included Applications
  • คลิกที่ Manage Devices
  • คลิกที่ Deauthorize All แล้วคลิก Done
  • จากนั้นกลับไปที่โปรแกรม SketchUp
  • Sign out และ Sign in ใหม่อีกครั้ง

ขั้นตอนอาจมีความแตกต่างเล็กน้อยขึ้นอยู่กับ Role ของคุณ

วิธีเปลี่ยนอีเมลผู้ใช้งาน

คุณสามารถแก้ไขอีเมลผู้ใช้งานได้จากหน้าจัดการใบอนุญาตของ SketchUp

ขั้นตอนเปลี่ยนอีเมลผู้ใช้งาน

  • ไปที่หน้าจัดการใบอนุญาต SketchUp License Portal
  • เข้าสู่ระบบด้วยบัญชีของคุณ
  • เลือกโปรไฟล์ชื่อบริษัท (Purchased via....)
  • เลือกเมนู Members
  • คลิกที่ปุ่ม ⁝ (จุดสามจุด) ด้านหลังอีเมลผู้ใช้งานที่ต้องการเปลี่ยน
  • คลิกเลือก Modify Product Access
  • คลิกยกเลิกโปรดักส์ (เพื่อดึงสิทธิ์คืนมา)
  • คลิกยืนยัน Save Product Access
    • หลังจากนี้คุณจะสามารถนำโปรดักส์นั้นไปเพิ่มให้ผู้ใช้งานท่านอื่นได้
  • เลือก Add New User เพื่อเพิ่มอีเมลผู้ใช้งานคนใหม่
  • ใส่อีเมลผู้ใช้งานใหม่ จากนั้นคลิก Next
  • เลือกโปรดักส์ SketchUp ที่ต้องการ แล้วคลิกที่ Add User
  • อีเมลใหม่จะถูกเพิ่มเข้ามาที่หน้าจัดการใบอนุญาตเรียบร้อย (สามารถทำซ้ำขั้นตอนเดิมหากต้องการเพิ่มท่านอื่น)
  • Change Role: แก้ไขผู้ใช้นั้นๆ ให้เป็นผู้ดูแลใบอนุญาตหรือเป็นผู้ใช้งาน
  • Modify Product Access: เพิ่ม-ลบ สิทธิ์ในการใช้งาน SketchUp
  • Remove User: ลบผู้ใช้งาน

ผู้ใช้งานใหม่จะมีสถานะเป็น (Status: Invited) และจะได้รับอีเมลคำเชิญจาก Trimble โปรดแจ้งให้ผู้ใช้งานกดรับคำเชิญทางอีเมล (ผู้มีสิทธิ์ใช้งานถูกต้องจะมีสถานะเป็น "1 Product..." หากไม่ได้รับสิทธิ์จะเป็น "None")

วิธีเช็ควันหมดอายุ สำหรับผู้ดูแลใบอนุญาต (Admin)

SketchUp Subscription สามารถเช็ควันหมดอายุได้แบบออนไลน์โดยผู้ดูแลใบอนุญาต (อีเมลที่ใช้สั่งซื้อหรือผู้ที่ได้รับสิทธิ์แอดมิน) ซึ่งจะมีข้อมูลที่จำเป็นทั้งหมดสำหรับการต่ออายุแสดงไว้อย่างชัดเจน

ขั้นตอนเช็ควันหมดอายุสำหรับผู้ดูแลใบอนุญาต

  • ไปที่หน้าจัดการใบอนุญาต SketchUp License Portal
  • เข้าสู่ระบบด้วยบัญชีผู้ดูแล (Admin)
  • เลือกโปรไฟล์ชื่อบริษัท (Purchased via....)
  • เลือกเมนู Plan Settings
  • วันหมดอายุ, ชื่อโปรดักส์ และจำนวนใบอนุญาตทั้งหมดจะแสดงอยู่ที่หน้านี้

หน้านี้จะเห็นวันหมดอายุของใบอนุญาตทั้งหมด เฉพาะผู้ดูแลใบอนุญาต (Admin) เท่านั้น ส่วนผู้ใช้งานทั่วไป (User) จะไม่สามารถเข้าถึงหน้านี้ได้

วิธีเช็ควันหมดอายุ สำหรับผู้ใช้งาน (User)

ผู้ใช้งานทั่วไป (User) ที่ได้รับสิทธิ์ใช้งาน SketchUp Subscription สามารถตรวจสอบวันหมดอายุของตนเองได้อย่างง่ายดายผ่านตัวโปรแกรม SketchUp โดยตรง

ขั้นตอนเช็ควันหมดอายุสำหรับผู้ใช้งาน

  • เปิดโปรแกรม SketchUp บนคอมพิวเตอร์ของคุณ
  • วันหมดอายุการใช้งานของคุณจะแสดงอยู่ที่ มุมด้านบนทางขวา ของหน้าต่าง Welcome
  • หรือคุณสามารถไปที่เมนูเมนูด้านบน เลือก Help >> Manage Licensing เพื่อตรวจสอบสถานะใบอนุญาตได้เช่นกัน

หากคุณเป็นผู้ดูแลใบอนุญาต (Admin) และต้องการดูรายละเอียดของทุกคนในองค์กร โปรดไปที่หัวข้อ วิธีเช็ควันหมดอายุ สำหรับผู้ดูแลใบอนุญาต

วิธีบันทึกไฟล์ SketchUp เป็นเวอร์ชั่นเก่า

SketchUp 2024 หรือใหม่กว่า จะไม่มีเครื่องมือสำหรับ Save as ไฟล์เป็นเวอร์ชั่นเก่าในตัว คุณจำเป็นต้องใช้ Extension เพิ่มเติมเพื่อช่วยในการบันทึกไฟล์ (อย่างไรก็ตาม ไฟล์ที่บันทึกด้วย SketchUp 2021 หรือใหม่กว่า สามารถเปิดใช้งานร่วมกันได้โดยไม่ต้องแปลงเวอร์ชั่น)

ขั้นตอนติดตั้ง Extension - Dezmo Save to older SketchUp Version

  • ดาวน์โหลดไฟล์ติดตั้งได้ ที่นี่ หรือไปที่ SketchUcation เพื่อดาวน์โหลด
  • คุณจะได้รับไฟล์นามสกุล .rbz สำหรับใช้ในการติดตั้ง
  • เปิดโปรแกรม SketchUp ขึ้นมา
  • เลือก Templates ใดก็ได้เพื่อเข้าสู่หน้าทำงาน (หากมี)
  • ที่เมนูด้านบน เลือก Extensions >> Extension Manager
  • จะมีหน้าต่างแสดงขึ้นมา ให้คลิกที่ปุ่ม Install Extension
  • ไปยังโฟลเดอร์ที่เก็บไฟล์ .rbz ที่คุณดาวน์โหลดไว้
  • คลิกเลือกไฟล์ .rbz แล้วคลิก Open
  • เครื่องมือ Dezmo จะแสดงขึ้นมาบนหน้าจอพร้อมใช้งาน
    • หากแถบเครื่องมือไม่แสดง ให้ไปที่เมนู View >> Toolbars >> ติ๊กถูกที่ Dezmo
  • คุณสามารถเลือกบันทึกไฟล์เป็นเวอร์ชั่นเก่าตามที่ต้องการได้ทันที
