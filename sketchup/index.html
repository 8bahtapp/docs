คำถามที่พบบ่อย

จัดการใบอนุญาต SketchUp ได้ที่ SketchUp License Portal โดย Sign in ด้วยอีเมล Admin ที่ใช้สั่งซื้อ

หลังการสั่งซื้อ Admin จะได้รับอีเมลยืนยัน จากนั้นเข้า SketchUp License Portal เพื่อเพิ่มผู้ใช้งานและมอบสิทธิ์การใช้งาน ผู้ใช้งานจะได้รับอีเมลเชิญพร้อมลิงก์เปิดใช้งาน

ต้องเชื่อมต่ออินเทอร์เน็ตสำหรับการเปิดใช้งานครั้งแรก หลังจากนั้นสามารถใช้งานแบบออฟไลน์ได้สูงสุด 28 วัน

ผู้ใช้งานต้องตั้งรหัสผ่านเองผ่าน Trimble Identity หากยังไม่มีบัญชีให้คลิก Create account ที่หน้า Sign in

ไปที่หน้า Sign in ของ SketchUp ใส่อีเมล แล้วคลิก "Forgot password" ระบบจะส่ง Verify Code ไปทางอีเมล

ให้ Sign out ออกก่อน แล้ว Sign in ใหม่ด้วยอีเมลที่ Admin มอบสิทธิ์ให้ หากยังไม่ได้รับสิทธิ์ให้ติดต่อ Admin เพื่อ Assign License ใน SketchUp License Portal

ดูวิธีการแก้ไขที่ วิธีรีเซ็ตใบอนุญาต

ได้ SketchUp Pro รองรับทั้ง Windows และ macOS รวมถึงใช้งานผ่านเว็บได้ที่ SketchUp for Web

Admin สามารถเช็ควันหมดอายุได้ที่ SketchUp License Portal → Subscriptions หรือดูคู่มือเพิ่มเติมที่ วิธีเช็ควันหมดอายุ (Admin)

ผู้ใช้งานทั่วไปสามารถดูได้ที่ วิธีเช็ควันหมดอายุ (User)

V-Ray ใช้งานได้สำหรับ SketchUp Studio Commercial เท่านั้น — V-Ray ไม่รวมในแผน Education / Student / Instructor

หรือคุณสามารถเลือกแผนการใช้งาน V-Ray เพิ่มเติมได้จาก คลิกที่นี่

ได้ SketchUp รองรับการบันทึกกลับเป็นเวอร์ชั่นเก่าได้ ดูวิธีการที่ วิธีบันทึกไฟล์เป็นเวอร์ชั่นเก่า

Admin ต้องถอดสิทธิ์อีเมลเดิมออกก่อน แล้วเพิ่มอีเมลใหม่ใน SketchUp License Portal ดูคู่มือได้ที่ วิธีเปลี่ยนอีเมลผู้ใช้งาน

โปรดไปที่ Open Ticket เจ้าหน้าที่จะติดต่อคุณในช่วงเวลาทำการ จันทร์–ศุกร์ 09:00–17:00
