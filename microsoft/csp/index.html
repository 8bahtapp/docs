การเข้าถึง Microsoft 365 Admin Center

  • ผู้ใช้งาน New Tenant: คุณจะได้รับ รหัสผ่านในการเข้าสู่ระบบในครั้งแรก — ต้องตั้งรหัสผ่านใหม่หลังจากนั้น
  • ผู้ใช้งานที่มี Tenant เดิมอยู่แล้ว: สามารถใช้ข้อมูลการเข้าสู่ระบบเดิมของคุณ

Microsoft บังคับใช้ MFA (Multi-Factor Authentication) อย่างเต็มรูปแบบสำหรับผลิตภัณฑ์ CSP — โปรดเพิ่มช่องทางยืนยันตัวตนสำรอง และตั้ง Admin สำรองไว้ทันที เพราะหากมือถือหายหรือแอปถูกลบ จะไม่สามารถเข้าสู่ระบบได้

วิธีจัดการใบอนุญาต

การจัดการใบอนุญาตทำได้ที่ Microsoft 365 Admin Center — ต้องมีสิทธิ์ Global Admin, License Admin หรือ User Admin

หากซื้อผ่าน CSP ไม่สามารถใช้หน้า Your Products ในการมอบสิทธิ์บางโปรดักส์ได้ — ให้ใช้หน้า Billing > Licenses แทน

เพิ่มผู้ใช้งานและมอบสิทธิ์

  • ไปที่ Microsoft 365 Admin Center
  • เข้าสู่ระบบด้วยบัญชีผู้ดูแลของคุณ
  • เลือก Billing > Licenses
    • หน้านี้จะแสดงโปรดักส์ทั้งหมด พร้อมจำนวน license ที่ใช้งานและคงเหลือ
  • เลือกโปรดักส์ที่ต้องการ
  • คลิก Assign licenses
  • พิมพ์ชื่อหรืออีเมลผู้ใช้งาน แล้วเลือกจากรายการ
  • สามารถเพิ่มได้สูงสุด 20 คนต่อครั้ง
    • หากต้องการมอบสิทธิ์จำนวนมาก แนะนำใช้ Group-based licensing
  • เลือก Turn apps and services on or off เพื่อกำหนดสิทธิ์เฉพาะบางบริการ (ถ้าต้องการ)
  • คลิก Assign เพื่อยืนยัน

แก้ไขสิทธิ์ผู้ใช้งาน

  • ไปที่ Users > Active users
  • คลิกชื่อผู้ใช้งานที่ต้องการแก้ไข
  • เลือกแท็บ Licenses and Apps
  • ทำเครื่องหมายหรือยกเลิกเครื่องหมายที่ License ที่ต้องการ
  • คลิก Save changes

อ่านเพิ่มเติมจาก Microsoft Learn: Assign or unassign licenses for users

ติดตั้งและเปิดใช้งาน

ผู้ใช้งานต้องได้รับ License จาก Admin ก่อน จึงจะสามารถดาวน์โหลดและติดตั้งโปรแกรมได้

ขั้นตอนดาวน์โหลดและติดตั้ง

  • ไปที่ m365.cloud.microsoft/apps
  • Sign in ด้วย Work/School account ที่ได้รับสิทธิ์
  • คลิก Install apps มุมขวาบน แล้วเลือก Microsoft 365 apps
    • หากไม่เห็นปุ่ม Install apps โปรดติดต่อ Admin เพื่อตรวจสอบว่าได้รับ License แล้วหรือไม่
  • ไฟล์ OfficeSetup.exe จะดาวน์โหลดมาที่โฟลเดอร์ Downloads
  • ดับเบิลคลิกไฟล์ที่ดาวน์โหลดมา แล้วคลิก Yes เพื่ออนุญาตให้ติดตั้ง
  • รอติดตั้งสักครู่ จนหน้าต่าง "You're all set!" ปรากฏขึ้น
  • คลิก Close — โปรแกรมพร้อมใช้งานในเมนู Start

เปิดใช้งาน (Activation)

  • เปิดโปรแกรมใดก็ได้ เช่น Word หรือ Excel
  • Sign in ด้วย Work/School account เดิม
  • โปรแกรมจะ Activate อัตโนมัติเมื่อเชื่อมต่ออินเทอร์เน็ต

อ่านเพิ่มเติมจาก Microsoft Learn: Install Microsoft 365 apps

ถอนใบอนุญาต

เมื่อถอน License ออกจากผู้ใช้งาน ข้อมูล Exchange Online จะถูกเก็บไว้ 30 วัน — ไฟล์ OneDrive จะไม่ถูกลบจนกว่าจะลบ User account ออกจากระบบ

วิธีถอน License จากผู้ใช้งาน (Admin)

  • ไปที่ Microsoft 365 admin center
  • เลือก Users > Active users
  • คลิกชื่อผู้ใช้งานที่ต้องการถอน License
  • เลือกแท็บ Licenses and Apps
  • ยกเลิกเครื่องหมายที่ License ที่ต้องการถอน
  • คลิก Save changes
  • License จะกลับมาอยู่ใน Pool และพร้อมมอบให้ผู้ใช้งานคนอื่นได้ทันที

อ่านเพิ่มเติมจาก Microsoft Learn: Unassign licenses for users

วิธีเพิ่มการยืนยันสองขั้นตอน MFA

ปัจจุบันทาง Microsoft จะบังคับให้ลูกค้าต้องเพิ่มการยืนยันสองขั้นตอน เพื่อความปลอดภัยในการเข้าถึงบัญชี — เพื่อความสะดวกในการเข้าถึง คุณควรติดตั้ง Microsoft Authenticator App เครื่องที่ 2 เผื่อกรณีโทรศัพท์มีปัญหา

ขั้นตอนเพิ่มการยืนยันสองขั้นตอน

  • ไปที่เว็บไซต์ My Account
  • เข้าสู่ระบบด้วยบัญชีของคุณ เช่น admin@name.onmicrosoft.com
  • เลือกเมนู Security info
  • คลิกปุ่ม + Add sign-in method
  • คุณสามารถเลือกรูปแบบการยืนยันสองขั้นตอนตามที่ต้องการได้ทันที
  • รูปแบบที่เชื่อมโยงกับบัญชีจะแสดงที่นี่ ซึ่งคุณสามารถแก้ไขหรือเปลี่ยนได้ในภายหลัง

Note: หากต้องการเปลี่ยนโทรศัพท์เครื่องใหม่ ต้องเพิ่ม Microsoft Authenticator App ที่เครื่องใหม่ให้ก่อนทำการเปลี่ยนหรือล้างเครื่องเดิม

คำถามที่พบบ่อย

ผู้ที่มีสิทธิ์จัดการ License ได้แก่ Global Admin, License Admin และ User Admin

ให้ผู้ใช้งานลองรอประมาณ 5–10 นาทีหลังจาก Admin มอบ License เนื่องจากระบบอาจใช้เวลาอัปเดตสิทธิ์ จากนั้นให้ Sign out แล้ว Sign in ใหม่ที่โปรแกรม หากยังไม่ได้ให้ลอง Restart เครื่องหนึ่งครั้ง

ไปที่ Users > Active users เลือกชื่อพนักงานเดิม แล้วไปที่แท็บ Licenses and Apps ยกเลิกเครื่องหมายที่ License แล้ว Save — จากนั้นเพิ่มหรือสร้างบัญชีผู้ใช้งานใหม่และมอบ License เดิมให้

ข้อมูล Exchange Online จะถูกเก็บไว้ 30 วัน หลังถอด License ก่อนถูกลบถาวร — ส่วนไฟล์ใน OneDrive จะไม่ถูกลบ จนกว่าจะลบ User account ออกจากระบบ

Microsoft 365 Business อนุญาตให้ผู้ใช้งาน 1 คน Sign in สูงสุดห้าเครื่อง
