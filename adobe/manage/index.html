หน้าแรก Adobe จัดการใบอนุญาต

วิธีจัดการใบอนุญาต

เมื่อสั่งซื้อสำเร็จคุณจะได้รับอีเมลยืนยันการสั่งซื้อ อีเมลที่สั่งซื้อสามารถแอดอีเมลผู้ใช้งานและจัดการใบอนุญาตทั้งหมด

การใช้งาน 1 ใบอนุญาตต่อ 1 อีเมล เช่น 5 ใบอนุญาตต้องใช้อีเมล 5 บัญชี

รับคำเชิญ

  • คุณจะได้รับอีเมลคำเชิญจาก Adobe ไปที่อีเมลที่คุณใช้สั่งซื้อ
    • ค้นหาอีเมลจาก message@adobe.com หากหาไม่พบ
  • คลิก Get started
  • Sign in ด้วยอีเมลผู้ดูแลระบบ
    • รีเซ็ตรหัสผ่านหากคุณจำรหัสผ่านเดิมไม่ได้
    • หากยังไม่มี Adobe ID โปรด Create account
  • คลิก Join team เพื่อเข้าร่วมทีม
  • เลือกโปรไฟล์ (ชื่อบริษัท)

เพิ่มผู้ใช้งาน

  • เข้าสู่หน้าจัดการใบอนุญาต Adobe Admin Console
  • คลิกที่ชื่อโปรดักส์ที่ต้องการ
  • คลิก Add User
  • ใส่อีเมลผู้ใช้งาน และคลิกที่ปุ่มลูกศรด้านหลัง (หากมี)
    • เลือก Add as a new user
    • ทำซ้ำขั้นตอนเดิมเพื่อเพิ่มอีเมลผู้ใช้งานท่านอื่น
  • ที่แถบเมนูด้านบนเลือก User
  • ผู้ใช้งานจะได้รับอีเมลคำเชิญเพื่อเริ่มต้นใช้งาน

จัดการผู้ใช้งานทั้งหมดได้จากหน้า Adobe Admin Console

ติดตั้งและเปิดใช้งาน

โปรดกดรับคำเชิญทางอีเมลก่อนเริ่มติดตั้ง

ติดตั้ง

  • ดาวน์โหลดไฟล์ติดตั้งจาก หน้า Adobe
  • เปิดไฟล์ติดตั้งและทำตามขั้นตอน
  • รอจนติดตั้งเสร็จสมบูรณ์

เปิดใช้งาน

  • เปิดโปรแกรม Creative Cloud
  • Sign in ด้วยอีเมลที่ได้รับคำเชิญ
  • เลือกโปรแกรมที่ต้องการติดตั้งและคลิก Install

ถอนใบอนุญาต

โปรดถอนใบอนุญาตก่อน Uninstall โปรแกรม หรือก่อนเปลี่ยนเครื่องคอมพิวเตอร์

Deactivate

  • เปิด Creative Cloud Desktop App
  • คลิกที่ชื่อบัญชีมุมขวาบน
  • เลือก Sign Out

คำถามที่พบบ่อย

หลังการสั่งซื้อ คุณจะได้รับอีเมลพร้อมลิงก์เปิดใช้งาน กดที่ลิงก์และเข้าสู่ระบบด้วยอีเมลที่ลงทะเบียนไว้

ใช่ จำเป็นต้องเชื่อมต่ออินเทอร์เน็ตสำหรับการเปิดใช้งานครั้งแรก หลังจากนั้นสามารถใช้งานแบบไม่เชื่อมต่ออินเทอร์เน็ตได้สูงสุด 99 วัน

ไปที่หน้าเข้าสู่ระบบและคลิก "ลืมรหัสผ่าน" เพื่อตั้งใหม่

คุณสามารถลงชื่อเข้าใช้ Adobe บนคอมพิวเตอร์สองเครื่องเท่านั้น และสามารถใช้งานแอปพลิเคชัน Adobe ได้บนคอมพิวเตอร์เพียงเครื่องเดียวในแต่ละครั้ง

โปรดไปที่ Open Ticket เจ้าหน้าที่จะติดต่อคุณในช่วงเวลาทำการ
