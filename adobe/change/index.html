Adobe Change reseller

วิธีเปลี่ยนตัวแทนจำหน่าย

Adobe ใช้ระบบ Admin Console เพื่อให้ลูกค้าจัดการใบอนุญาตได้ด้วยตัวเอง ซึ่งเชื่อมโยงใบอนุญาตกับ Reseller ที่ดูแลอยู่ การเปลี่ยน Reseller จำเป็นต้องอัปเดตข้อมูลนี้เพื่อให้ Reseller ใหม่สามารถจัดการและให้บริการได้อย่างถูกต้อง

ขั้นตอน

  • ไปที่ Adobe Admin Console
  • Sign in ด้วยอีเมล Admin
  • เลือกโปรไฟล์ที่ต้องการ (ปกติจะเป็นชื่อบริษัท)
    • หากมีใบอนุญาตหลายครั้งอาจมีโปรไฟล์ให้เลือกหลายโปรไฟล์
  • ที่แถบเมนูสีดำด้านบน ไปที่หัวข้อ Account
  • ที่หัวข้อ Account manager คลิกที่รูปดินสอ ✎ เพื่อสร้าง Code
  • คลิก Generate Code
  • จะมีชุดตัวเลขแสดงขึ้นมา คลิก Copy code
  • จากนั้น โปรดส่งชุดตัวเลขดังกล่าวพร้อมกับ Customer ID ให้กับตัวแทนจำหน่ายใหม่
  • หรือส่งข้อมูลไปที่ support8baht@applicadthai.com

ชุดตัวเลขดังกล่าวมี อายุการใช้งาน 72 ชั่วโมง

ข้อมูลเพิ่มเติม

  • คำถามที่พบบ่อย
  • วิธีค้นหา Customer ID
  • วิธีเช็ควันหมดอายุ
  • วิธีเปลี่ยนอีเมลผู้ใช้งาน
