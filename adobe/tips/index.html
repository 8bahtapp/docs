วิธีค้นหา Customer ID

Customer ID หรือ Account ID (ก่อนหน้านี้จะเรียกว่า VIP Number) คือหมายเลขที่ใช้ระบุการสมัครสมาชิกขององค์กร ซึ่งสำคัญสำหรับการต่ออายุหรือจัดการบัญชีของคุณ

ขั้นตอน

  • ไปที่ Adobe Admin Console
  • Sign in ด้วยอีเมล Admin
  • เลือกโปรไฟล์ที่ต้องการ (ปกติจะเป็นชื่อบริษัท)
    • หากมีการสั่งซื้อก่อนหน้าหลายครั้ง อาจมีโปรไฟล์ให้เลือกหลายโปรไฟล์
    • มองหาชื่อบริษัทที่มุมบนขวา คลิกเพื่อเปลี่ยนโปรไฟล์
  • ที่แถบเมนูสีดำด้านบน ไปที่หัวข้อ Account
  • Customer ID จะแสดงเป็น Account ID (ตัวอย่าง 100XXXXXXX)

วิธีค้นหา Anniversary date

Anniversary date คือวันครบรอบหรือวันหมดอายุของ Adobe

ขั้นตอน

  • ไปที่ Adobe Admin Console
  • Sign in ด้วยอีเมล Admin
  • เลือกโปรไฟล์ที่ต้องการ (ปกติจะเป็นชื่อบริษัท)
    • หากมีการสั่งซื้อก่อนหน้าหลายครั้ง อาจมีโปรไฟล์ให้เลือกหลายโปรไฟล์
    • มองหาชื่อบริษัทที่มุมบนขวา คลิกเพื่อเปลี่ยนโปรไฟล์
  • ที่แถบเมนูสีดำด้านบน ไปที่หัวข้อ Account
  • มองหาคำว่า Anniversary date คุณจะพบวันหมดอายุ

วิธีเปลี่ยนอีเมลผู้ใช้งาน

การเปลี่ยนอีเมลผู้ใช้งานทำโดย Admin โดยต้องนำ License ออกจากอีเมลเดิม แล้วเพิ่มอีเมลใหม่เข้าไปในระบบ

ถอดสิทธิ์ผู้ใช้งานเดิม

  • ไปที่ Adobe Admin Console
  • Sign in ด้วยอีเมล Admin
  • เลือกโปรไฟล์ที่ต้องการ (ปกติจะเป็นชื่อบริษัท)
    • หากมีการสั่งซื้อก่อนหน้าหลายครั้ง อาจมีโปรไฟล์ให้เลือกหลายโปรไฟล์
    • มองหาชื่อบริษัทที่มุมบนขวา คลิกเพื่อเปลี่ยนโปรไฟล์
  • ที่แถบเมนูสีดำด้านบน ไปที่หัวข้อ Users
  • คุณจะพบกับผู้ใช้งานทั้งหมด
    • สิทธิ์การใช้งาน Apps จะแสดงเป็น icon ต่อท้ายผู้ใช้งานแต่ล่ะคน
  • คลิกที่ ชื่อผู้ใช้งานที่ต้องการ
  • มองหาหัวข้อ Products
  • คลิกที่ถังขยะ 🗑 เพื่อลบ App ออกจากผู้ใช้งานเดิม
  • ถอดสิทธิ์ผู้ใช้งานเดิมสำเร็จ

เพิ่มผู้ใช้งานใหม่

  • ที่แถบเมนูสีดำด้านบน ไปที่หัวข้อ Users
  • คลิก Add users
  • ใส่อีเมลผู้ใช้งาน และคลิกที่ปุ่มลูกศรด้านหลัง (หากมี)
    • เลือก Add as a new user
  • ที่หัวข้อ Product คลิก +
  • เลือก Apps คลิก Apply
  • กด Save
  • เพิ่มผู้ใช้งานใหม่สำเร็จ

คุณสามารถเช็คสถานะผู้ใช้งานและ Apps ทั้งหมดได้ทั้งจากเมนู Overview, Products หรือ Users
